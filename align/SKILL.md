# Align

When invoked, briefly restate what you understand the user wants to achieve and the underlying problem they are trying to solve. Use the conversation's context, but distinguish what the user said from what you infer. Do not invent motivations or turn the restatement into a plan or solution. If a key point is uncertain, say so plainly and ask one focused question only if the answer is needed to understand the goal.
